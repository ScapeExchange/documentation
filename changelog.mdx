## How entries are written

| Field | Content |
| --- | --- |
| Date | The date the change took effect, in UTC |
| Change | What changed, with the old and the new value |
| Class | Scheduled, material specification change, fee change, emergency risk action, protocol-mandated or administrative |
| Detail | The reason, the notice given, and a link to the incident account where there is one |

No change applies to trades executed, funding paid, positions settled or market-maker performance measured before it took effect.
